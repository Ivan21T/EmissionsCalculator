# Fuel Emissions Calculator

> **An Android application for calculating fuel emissions and exporting the results into tabular reports.**

The Fuel Emissions Calculator is a mobile application developed in **Java** using **Android Studio**. The application calculates emissions generated by different fuel types and exports the results into tabular reports. It was developed for **EAP Plovdiv** to simplify environmental calculations and improve reporting efficiency.

---

# 🚀 Features

* ⛽ Fuel emissions calculation
* 📊 Automatic calculation using emission factors
* 📄 Export results into tabular reports
* 📱 Android mobile application
* ⚡ Fast and accurate calculations
